# PROFORMA DASHBOARD V5.7 — VISUAL BI

## Objetivo
Esta versión corrige la principal brecha visual de V5.6: la aplicación ya no se limita a mostrar tablas, sino que reconstruye los principales indicadores y gráficos del Excel como componentes BI interactivos y responsivos.

## Cambios
- Resumen Ejecutivo con KPIs, comparación 2025/2026, aportes por zona y oportunidad por zona.
- Objetivo 2026 con avance versus meta y cumplimiento.
- Comparativos con gráficos por zona.
- Comp 2025-2026 con aportes por zona y variación porcentual.
- Comparativo Parcial con aportes por cartera.
- Comp Aportes con filtros, KPIs, rankings y gráficos.
- Análisis 80/20 con Pareto, línea acumulada 80% y torta Top 5/Otros.
- Oportunidad de Crecimiento con rankings por empresa, ejecutiva y zona, y actual vs potencial.
- Tablas modernas con búsqueda, paginación, encabezado fijo, formato CLP y porcentajes.
- Identidad visual Proforma: naranja #F28C28, blanco, grises y tarjetas ejecutivas.
- Diseño responsive para escritorio, tablet y móvil.
- Se mantiene la conexión existente GitHub Pages → Render y la autenticación V5.6.

## Nota
Los gráficos se calculan a partir de los datos reales entregados por los endpoints del XLSM; no se usan imágenes estáticas de Excel.
